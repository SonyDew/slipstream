# Slipstream project identity

The AGPL licence in this repository grants rights to the source code. It does not grant
permission to present a modified or independently operated product as an official
Slipstream release.

You may use the name **Slipstream** truthfully to describe compatibility or origin, for
example: “based on Slipstream” or “a fork of Slipstream”. Public forks and derivative
distributions should use a distinct product name and visual identity unless the project
maintainer has given written permission to use the original identity.

Do not use the Slipstream name, logo, screenshots or other brand assets in a way that:

- suggests sponsorship, endorsement or official status;
- makes a modified build difficult to distinguish from an official release;
- misrepresents the origin or authorship of the project; or
- removes existing copyright and licence notices.

This policy does not restrict nominative or other legally permitted fair use. It exists
to keep unofficial builds identifiable while leaving the AGPL freedoms for the code
intact.
